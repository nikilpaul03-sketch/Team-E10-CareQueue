Technology Stack & Development Roadmap

Team E10 follows an enterprise-grade 10-phase roadmap designed for academic excellence and industry rigor.

Approved Technology Stack
  • Language Java 21 (Temurin LTS)
  • Backend Framework Spring Boot 3.3.5
  • Frontend UI Thymeleaf + Bootstrap 5
  • Database Engine MySQL 8.x + Hibernate JPA
  • Build & Dependency Maven Wrapper (mvnw.cmd)
  • IDE Compatibility Eclipse IDE / Google Antigravity
